## Replicar el Entorno Local

Si deseas revisar el código o ejecutar las consultas localmente:
1.  Clona este repositorio.
2.  Las bases de datos necesarias están diseñadas para ejecutarse en contenedores. Puedes levantar una instancia local (por ejemplo, `Lituus_SQL_Server`) utilizando los archivos de configuración incluidos.
3.  Utiliza Azure Data Studio o la extensión de bases de datos en VS Code para conectarte al servidor y ejecutar los scripts provistos en cada módulo.
